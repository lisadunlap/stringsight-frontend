Dependencies
============

External:
  • js-yaml ^4.1.0 - YAML parsing
  • jszip ^3.10.1 - ZIP extraction
  • react ^18.0.0 - Hooks (peer)

Internal (none!):
  ✅ Fully self-contained
  ✅ No imports from parent app
  ✅ No StringSight-specific code

Data Flow
=========

User visits URL
    ↓
useDatasetFromUrl hook
    ↓
getDatasetNameFromUrl() extracts "telecom"
    ↓
fetchDatasetsConfig() loads public/datasets.yaml
    ↓
loadDataset("telecom")
    ↓
constructFileUrl() → /api/results/zip/telecom_2026-01-02.zip
    ↓
loadDatasetFromZip()
    ↓
JSZip extracts conversations.jsonl, properties.jsonl, etc.
    ↓
Returns LoadedDataset { conversations, properties, clusters, metrics }
    ↓
App renders data

Backend Integration
===================

Required endpoint:
  GET /results/zip/{filename}

Expected response:
  Content-Type: application/zip
  Status: 200 OK
  Body: ZIP file containing JSONL data

Frontend proxy (Vite):
  /api/* → http://localhost:8000

ZIP Contents
============

conversations.jsonl         [Required] Main data
properties.jsonl            [Optional] Extracted properties  
clusters.jsonl              [Optional] Cluster assignments
model_cluster_scores_df.jsonl [Optional] Model-cluster metrics
cluster_scores_df.jsonl     [Optional] Cluster metrics
model_scores_df.jsonl       [Optional] Model metrics
